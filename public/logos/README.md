# /public/logos

Drop official brand SVGs here. Each file must match the slug used in `tools-section.tsx`.

Expected filenames:
  n8n.svg, anthropic.svg, openai.svg, clickup.svg, apify.svg,
  webflow.svg, airtable.svg, googlesheets.svg, slack.svg, make.svg,
  zapier.svg, notion.svg, hubspot.svg, linear.svg, supabase.svg,
  postgresql.svg, figma.svg, github.svg

Download source: https://simpleicons.org — search the tool name, download SVG.

Until a local file exists the component falls back to the Simple Icons CDN automatically.
